== Encoding Spec
[cols="1,1,1"]
|===
|type
|sexp type
|sexp value

|void
|list
|()

|bool
|atom
|true/false

|option
|atom/list
|none/(some x)

|seq
|list
|values

|map
|list
|((key value) ...)

|str
|str
|quoted string with escaped \" \\ \n \r \t, \u{…}

|decimal
|atom
|exact value at type's scale

|record
|list(list..)
|((field value) ...)

|enum
|atom
|member

|variant
|list(atom + list..)
|(member (field value) ...)
|===

=== Ordering
[cols="1,1"]
|===
|type
|ordering

|seq
|keeps given order

|map
|keys ordered based on types*

|record
|fields in declaration order

|enum
|members in declaration order

|variant
|members & fields in declaration order
|===

==== Map Key Ordering
[cols="1,1"]
|===
|key type
|ordering

|bool
|false, true

|decimal
|unscaled after rescaling into type's scale

|str
|code point comparison

|enum
|member tags
|===

NOTE: No other types are allowed for keys of maps

== Decoding Spec
* Fields in any order
* Less decimal places than in type
