=== Ordering

|===

|ordering

==== Map Key Ordering
[cols="1,1"]
|===
|key type
|ordering

|bool
|`false`, `true`

|decimal
|unscaled after rescaling into type's scale

|bytes
|byte by byte unsigned comparison, with prefixes first

|str
|code point comparison

|enum
|member tags

|alias
|target type's ordering
|===

NOTE: No other types are allowed for keys of maps

== Decoding Spec
* Fields in any order
* Map entries in any order
* Bytes normalize to lowercase
* Less decimal places than in type
* ASCII digits only for decimals
* Values like 007 and -0 are normalized to 7 and 0
* Any error existing means no value, though lenient functions are in the docs as an option
* Comments (`; Something`) are currently ignored
