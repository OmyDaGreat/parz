= S Expression Details

== Encoding Spec

[cols="1,1,1"]
|===
|type
|sexp type
|sexp value

|void
|list
|()

|bool
|atom
|true/false

|option
|atom/list
|none/(some x)

|seq
|list
|values

|map
|list
|((key value) ...)

|str
|str
|quoted string with escaped \" \\ \n \r \t, \u{…}

|decimal
|atom
|exact value at type's scale

|record
|list(list..)
|((field value) ...)

|enum
|atom
|member

|variant
|list(atom + list..)
|(member (field value) ...)
|===

NOTE: Fields + values are in declaration order while encoding

== Decoding Spec

* Fields in any order
* Less decimal places than in type
