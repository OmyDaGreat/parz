Decimal

data class Decimal(val min: BigInteger, val max: BigInteger, val scale: Int, val rounding: Type.Decimal.Rounding = Rounding.TOWARDS_ZERO, val overflow: Type.Decimal.Overflow = Overflow.ERROR) : Type

A decimal type. min and max are inclusive unscaled big integers, allowing for easier comparison with the unscaled value of a decimal.

Decimal types with scale of 0 are referred to as Integers.
